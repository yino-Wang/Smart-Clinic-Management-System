# ClinicFlow 🏥

A full-stack clinic management system built with **ASP.NET Core Web API** and **React + TypeScript**.

## Tech Stack
### Backend
- ASP.NET Core (.NET)
- C#
- RESTful API
- Swagger / OpenAPI

### Frontend
- React
- TypeScript
- Vite
- Axios

## Features
- Health check API
- Frontend–backend integration
- Swagger API documentation
- Modular project structure

## Project Structure
clinicflow
├─ backend
│ └─ ClinicFlow.Api
├─ frontend
│ └─ clinicflow-web
